                               THE 4 PROBLEMS
================================================================================

1. NO HIGHLIGHT - Long phrases not found
   Example: "Notwithstanding anything in this Agreement to the contrary..."
   Status: Text not found (no highlight appears)
   Root: Multi-item text, normalization issues

2. FALSE POSITIVE - Wrong items highlighted
   Example: Searching "(xi)" highlights both "(x)" and "(xi)"
   Status: Multiple items highlighted
   Root: Substring matching + punctuation removal

3. WRONG SECTION - Highlights unrelated items
   Example: Searching "(b)" highlights both "(a)" and "(b)"
   Status: Multiple items highlighted
   Root: Same as Problem 2

4. WRONG WIDTH - Highlight box incorrect size/position
   Example: "(c) consolidate..." highlight too small or offset
   Status: Highlight misaligned/incorrect size
   Root: Spanning match includes wrong items

================================================================================
                            ROOT CAUSE SUMMARY
================================================================================

LINE 1580: .replace(/[^\w\s]/g, '')
  PROBLEM: Removes ALL punctuation
  EFFECT: "(xi)" becomes "xi", "(x)" becomes "x"
  RESULT: Can't distinguish between them

LINE 1589 & 1598: .includes()
  PROBLEM: Substring matching without boundaries
  EFFECT: Finds ANY substring, not full words
  RESULT: "(b)" matches "(ab)", "xi" matches "x"

LINES 1606-1626: Spanning match logic
  PROBLEM: Combines up to 10 items from every starting position
  EFFECT: Includes wrong items in group
  RESULT: Oversized/wrong highlights

LINES 1654-1678: Bounding box calculation
  PROBLEM: Spans from first to last item in group
  EFFECT: Doesn't match actual search bounds
  RESULT: Highlight misaligned
