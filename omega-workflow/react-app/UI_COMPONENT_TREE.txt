COMPONENT USAGE IN WORKFLOW WIZARD (Phase 2)
─────────────────────────────────────────────────────────────

Step 1: Basic Info
├── Input           → Workflow name
├── Textarea        → Workflow description
├── Select          → Category/type selection
└── Checkbox        → Active/enabled toggle

Step 2: Triggers
├── SearchInput     → Search available triggers
├── RadioGroup      → Trigger type selection
├── Select          → Specific trigger options
└── Checkbox        → Enable/disable conditions

Step 3: Actions
├── SearchInput     → Search available actions
├── RadioGroup      → Action type selection
├── Select          → Specific action options
└── Textarea        → Action configuration

Step 4: Conditions
├── RadioGroup      → Condition type
├── Select          → Field selection
├── Select          → Operator selection
└── Input           → Value input

Step 5: Review
├── Card            → Summary display
├── Checkbox        → Confirmation checkbox
└── Button          → Submit/Save

Overall Navigation
└── Stepper         → Progress indicator (all steps)
